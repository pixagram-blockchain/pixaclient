    Class BroadcastAPI

    Broadcast API helper.

    Part of the lite (fetch-only) client: the signing it needs comes from the crypto module through crypto-registry.ts, so client.broadcast exists even before @pixagram/dpixa/crypto has been loaded. Methods that sign or compute transaction ids throw a descriptive error until it is.

    delegateVestingShares

    • delegateVestingShares(
          options: {
              delegatee: string;
              delegator: string;
              vesting_shares: string | Asset;
          },
          key: PrivateKey,
      ): Promise<TransactionConfirmation>

      Delegate vesting shares from one account to the other. The vesting shares are still owned by the original account, but content voting rights and bandwidth allocation are transferred to the receiving account. This sets the delegation to vesting_shares, increasing it or decreasing it as needed. (i.e. a delegation of 0 removes the delegation)

      When a delegation is removed the shares are placed in limbo for a week to prevent a satoshi of VESTS from voting on the same content twice.

      Parameters

      • options: { delegatee: string; delegator: string; vesting_shares: string | Asset }

        Delegation options.

        • delegatee: string

          The account receiving vesting shares.

        • delegator: string

          The account delegating vesting shares.

        • vesting_shares: string | Asset

          The amount of vesting shares delegated.

      • key: PrivateKey

        Private active key of the delegator.

      Returns Promise<TransactionConfirmation>

    • promote(

              amount: string | Asset;
              author: string;
              from: string;
              permlink: string;
          },
          key: PrivateKey | PrivateKey[],
      ): Promise<TransactionConfirmation>

      Promote a post: burn PXS for it by sending it to null with the memo @author/permlink. Pixamind adds the amount to the post's promoted total, which ranks the promoted feed while the post awaits its payout. Only a root post can be promoted, only PXS counts, and the PXS is burned whatever happens to the post.

      Parameters

      • data: { amount: string | Asset; author: string; from: string; permlink: string }

        from pays, author/permlink name the post, amount in PXS (from 0.001).

      • key: PrivateKey | PrivateKey[]

        Private active key of from.
